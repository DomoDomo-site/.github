## 01 — ABOUT

**DomoDomo** is an open-source collective building software, developer
tools, AI experiments, digital products, and ideas designed to be useful,
accessible, and open to everyone.

We are not building a single product.

We are building an ecosystem.

Projects can exist independently while sharing a common home, a common
philosophy, and a common belief that good software becomes more valuable
when people can explore, understand, and build upon it.

```text
                              DOMODOMO
                                 │
             ┌───────────────────┼───────────────────┐
             │                   │                   │
          SOFTWARE             AI / ML          DEVELOPER TOOLS
             │                   │                   │
             └───────────────────┼───────────────────┘
                                 │
                          OPEN SOURCE
                                 │
                            COMMUNITY
```

## 02 — WHY DOMODOMO

The internet is full of software.

There are tools for developers, platforms for creators, frameworks for
researchers, and countless experiments scattered across repositories.

DomoDomo is a place to bring some of those ideas together.

We build because we are curious.

We open-source because knowledge should travel.

We experiment because not every idea needs to start perfectly.

We share because someone else might take an unfinished idea and turn it
into something better.

> **Build useful things. Share what you learn. Keep building.**

---

## 03 — THE ECOSYSTEM

DomoDomo is a collection of projects rather than one monolithic platform.

Each project has its own purpose, repository, technology, and direction.

### `DomoSkills`

An open-source ecosystem for discovering, organizing, and installing
reusable skills for AI coding agents.

The goal is to make structured engineering knowledge easier for developers
and AI agents to discover, reuse, and maintain.

---

### `DomoScope`

An open-source GitHub repository intelligence and architecture exploration
tool.

DomoScope helps developers understand unfamiliar codebases by exploring
their structure, dependencies, relationships, important files, and
architecture.

---

### `DomoNote`

A lightweight note-taking application focused on writing, organization,
and keeping ideas accessible without unnecessary complexity.

---

### `More`

DomoDomo is continuously evolving.

Some projects begin as experiments.

Some become tools.

Some become products.

Some simply teach us something new.

They all have a place here.

## 05 — OUR PHILOSOPHY

### BUILD

Ideas become valuable when they become real.

We turn concepts into prototypes, prototypes into projects, and projects
into software that people can actually use.

### EXPLORE

Not every experiment needs to succeed.

Trying unfamiliar technologies, architectures, models, and ideas is part
of the process.

### SHARE

Source code is only one part of open source.

We share documentation, experiments, discoveries, failures, and the lessons
behind the work.

### LEARN

Every project is an opportunity to learn something new.

### CONTRIBUTE

Software becomes stronger when more people can participate.

## 06 — OPEN SOURCE

Open source is not an afterthought at DomoDomo.

It is part of how we build.

Whenever practical, our projects aim to provide:

```text

Contribution Guidelines
```

## 10 — PROJECT LIFECYCLE

Not every repository has the same level of maturity.

Projects may move through different stages:

| Stage | Meaning |
| --- | --- |
| `EXPERIMENT` | An early idea or technical exploration |
| `PROTOTYPE` | A working proof of concept |
| `DEVELOPMENT` | Actively being built |
| `BETA` | Usable while still evolving |
| `STABLE` | Mature and actively maintained |
| `ARCHIVED` | No longer actively developed |

An experiment does not have to become a product.

An unfinished project is not necessarily a failed project.

Sometimes an experiment exists simply to answer a question.
